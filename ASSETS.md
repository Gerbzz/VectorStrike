# Asset attribution

This table records the retained non-code assets in the VectorStrike source checkpoint. Original VectorCraft contributor art remains attributed to its authors; third-party fonts and icons retain their own license notices. The table is an attribution index, not a new license grant for VectorStrike modifications or its temporary UI mark.

The included `assets/fonts/` files are the upstream Latin UI/document fonts with their OFL notices. `assets/icons/` contains the compiled icon set and `LICENSE-lucide.txt`; examples are retained as source documents. The optional external `CRAFT_FONTS_DIR` font checkout is not included and is not required for the baseline build.

Donor dragon app icons, ArtCraft trademark artwork, documentation screenshots, and DMG artwork are omitted from this candidate, so their old index rows have been removed. See `NOTICE` for upstream source and third-party attribution.
